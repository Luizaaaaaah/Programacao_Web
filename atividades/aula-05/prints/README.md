# Capturas de tela — Aula 05

A estudante forneceu nove capturas reais da aplicação React na Vercel. Elas foram reunidas e nomeadas em um ZIP disponibilizado nesta conversa, **mas ainda não foram anexadas nesta pasta do GitHub**. Os nomes abaixo correspondem aos PNGs prontos para upload.

## Arquivos esperados

- 01-menu-inicial.png — cabeçalho e navegação
- 02-todo-list.png — tarefa Estudar React cadastrada
- 03-contador.png — contador de cliques
- 04-jogo-da-velha.png — partida e resultado
- 05-calculadora.png — cálculo realizado
- 06-buscador-cep.png — consulta ViaCEP
- 07-github-commits.png — commits
- 08-vercel-deploy.png — publicação
- 09-site-publicado.png — publicação aberta no navegador (opcional, a imagem 01 já mostra a página publicada)
- 10-todo-vazio.png — tela inicial sem tarefas
- 11-todo-concluido.png — tarefa Estudar React concluída
- 12-todo-removido.png — lista vazia após exclusão

## Padrão de nomeação

Use dois dígitos no início, letras minúsculas e hífens. Evite espaços, acentos e parênteses. Não inclua senhas, tokens, chaves ou dados pessoais sensíveis nas capturas.

**Arquivos prontos no ZIP:** 01, 02, 03, 04, 05, 06, 10, 11 e 12 (todos PNG). Os itens 07 e 08, caso sejam requeridos, devem ser capturados separadamente no GitHub e na Vercel. Após o upload dos nove PNGs na branch `reorganizacao`, conferir os arquivos e inserir os links no relatório da Aula 05.
