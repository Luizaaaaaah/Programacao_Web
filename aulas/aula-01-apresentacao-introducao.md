A disciplina de Programação Web combina conceitos de design visual com tecnologias de desenvolvimento para criar interfaces e aplicações web funcionais.

Os alunos foram convidados a compartilhar:

- Experiências profissionais na área de tecnologia;
- Expectativas após a conclusão do curso;

O professor apresentou sua formação acadêmica e experiência profissional, destacando sua atuação em Ciência da Computação, Inteligência Artificial, desenvolvimento de sistemas e gerenciamento de projetos.

## 2. Plano de aulas e ensino

Foram apresentados os principais elementos do planejamento da disciplina:

- Objetivos de aprendizagem;
- Ementa;
- Conteúdo programático;
- Metodologia de ensino;
- Recursos didáticos;

O conteúdo programático inclui planejamento, versionamento, desenvolvimento front-end e back-end, hospedagem e banco de dados.

## 3. Versionamento e deploy

O controle de versões permite registrar alterações realizadas nos arquivos de um projeto, facilitando o acompanhamento do desenvolvimento.

Entre seus benefícios estão:

- Recuperação de versões anteriores;
- Colaboração entre desenvolvedores;
- Criação de branches para desenvolvimento paralelo;
- Organização do histórico de alterações.

Foram apresentados sistemas de controle de versões como GitHub, GitLab e Bitbucket.

### Deploy

Deploy é o processo de disponibilizar uma aplicação em um ambiente onde ela possa ser utilizada.

A aula também introduziu ambientes de desenvolvimento, métodos de implantação, integração contínua e entrega contínua (CI/CD).

## 4. Arquitetura de um site

A arquitetura de um site envolve a definição de sua estrutura, organização, funcionalidades e navegação.

Foram abordados:

- Definição do escopo do projeto;
- Organização da arquitetura da aplicação;
- Experiência do usuário (UX);
- Interface do usuário (UI);
- Validação de ideias e prototipação;
- Melhorias contínuas de usabilidade.

A prototipação permite representar visualmente uma solução antes de sua implementação.

## 5. Introdução ao JavaScript

JavaScript é uma linguagem de programação utilizada no desenvolvimento web, principalmente para implementar comportamentos e funcionalidades nas páginas.

Ela permite:

- Manipular elementos de páginas web;
- Implementar lógica de interface;
- Responder às interações do usuário;
- Realizar comunicação com servidores.

### Vanilla JavaScript

Vanilla JS é o uso do JavaScript puro, sem bibliotecas ou frameworks adicionais.

Seu aprendizado permite compreender os fundamentos utilizados por ferramentas modernas de desenvolvimento front-end.

## 6. Servidores, hospedagem e CMS

A hospedagem permite disponibilizar um site na internet por meio de um servidor.

Um **CMS (Content Management System)** é um sistema de gerenciamento de conteúdo que facilita a criação, edição e manutenção de sites.

As principais funcionalidades apresentadas incluem:

- Criação e gerenciamento de páginas;
- Configuração e personalização de sites;
- Instalação de plugins;
- Gerenciamento de conteúdos;
- Utilização de ferramentas visuais.

## 7. Website Builders

Website Builders são ferramentas que permitem criar sites por meio de interfaces visuais, reduzindo a necessidade de programação manual.

### Vantagens

- Facilidade de utilização;
- Rapidez na criação de sites;
- Planos com hospedagem e manutenção;
- Templates prontos e responsivos.

### Limitações

- Menor flexibilidade para funções específicas;
- Possíveis impactos no desempenho;
- Dificuldade de migração entre plataformas.

Essas ferramentas são alternativas para a criação de sites sem desenvolvimento manual de toda a estrutura.

## 8. Frameworks Front-end

Frameworks e bibliotecas front-end auxiliam na construção de interfaces web, oferecendo estruturas e ferramentas para organizar o desenvolvimento.

As tecnologias apresentadas foram:

- **React:** biblioteca utilizada na criação de interfaces baseadas em componentes;
- **Angular:** framework para o desenvolvimento de aplicações web;
- **Vue.js:** framework progressivo para construção de interfaces.

### Principais conceitos

- Componentização e reutilização de código;
- Organização da estrutura da aplicação;
- Gerenciamento de estado;
- Roteamento entre páginas;
- Integração com APIs.

## 9. Frameworks Back-end

O back-end é responsável pelo processamento de informações e pela lógica executada no servidor.

Os frameworks back-end auxiliam na organização e implementação de aplicações web.

Entre os assuntos apresentados estão:

- Arquitetura e padrões de desenvolvimento;
- Modelo MVC (Model-View-Controller);
- APIs RESTful;
- Integração com bancos de dados;
- Autenticação e segurança;
- Gerenciamento de usuários.

Esses recursos contribuem para a organização e manutenção dos sistemas.

## 10. Bancos de dados NoSQL

Os bancos de dados NoSQL utilizam modelos não relacionais para armazenar informações.

### Características

- **Flexibilidade:** permitem estruturas de dados dinâmicas;
- **Armazenamento:** suportam diferentes formatos de informações;
- **Escalabilidade:** podem distribuir dados entre vários servidores.

Essas características tornam o NoSQL uma alternativa para aplicações que necessitam de estruturas flexíveis e expansão de capacidade.

## 13. Atividade proposta

A primeira atividade da disciplina foi dividida em quatro etapas.

### Etapa 1 — Formação dos grupos

Formar grupos de **3 a 5 integrantes**, mantendo a mesma composição durante as atividades semanais.

### Etapa 2 — Propostas de projetos

Reunir os integrantes para discutir ideias e elaborar propostas de projetos a serem desenvolvidos durante o semestre.

As propostas deverão ser apresentadas ao professor.

### Etapa 3 — Repositório no GitHub

Criar um repositório para centralizar as atividades da disciplina.

O repositório deverá conter um arquivo Markdown (`.md`) apresentando um resumo da Aula 01, com os principais conceitos discutidos.

### Etapa 4 — Análise de sites no Miro

Selecionar três sites e pesquisar quais tecnologias foram utilizadas em sua construção.

Na ferramenta Miro, elaborar colaborativamente uma representação visual dos sites escolhidos e das tecnologias identificadas.

A imagem produzida deverá ser salva no repositório do GitHub.
